当前版本

下载之前，你可能想知道。

需要自己安装 Python 吗？+

不需要。安装包已包含 Python、桌面界面依赖和文字识别模型。

可以离线翻译吗？+

不支持离线翻译。文字识别在本机进行，翻译需要联网并填写你自己的 DeepSeek API Key。

后续怎么更新？会影响我的工程吗？+

目前通过下载新版安装包覆盖安装来更新，尚不支持软件内自动更新。设置独立保存；请把漫画工程放在安装目录外。后续新版发布前会验证升级兼容性。
